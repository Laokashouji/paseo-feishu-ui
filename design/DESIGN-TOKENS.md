# Paseo 飞书桌面设计令牌

默认主题为暗黑；亮色主题不是反色计算，而是绑定独立表面、选择、悬停、弹层与输入状态。

| `--frame-end` | `#2e3438` | 外框底部灰蓝 |
| `--gutter` | `#30383c` | 列表与聊天之间的 6px 实体间隔 |
| `--groups` | `#1e1f22` | 分组栏 |
| `--canvas` | `#181818` | 列表与聊天画布 |
| `--paper` | `#1d1d1d` | Composer 与实底控件 |

| `--group-selected` | `#29344c` | 当前分组 |

| `--muted` | `#737373` | 时间、提示与弱图标 |

## 几何与间距

- 1342×750 桌面网格：`180px 应用导航 / 160px 分组 / 300px 列表 / 6px gutter / 690px 聊天 / 6px 右外框`。
- 分组+列表联合面板：`x=180–640`、`y=6–744`；外侧圆角 8px。
- 聊天独立面板：`x=646–1336`、`y=6–744`；四角圆角 8px。
- 导航与分组行高 36px；会话行高 60px；列表头像 36px；消息头像 32px。
- 聊天头部 70px：标题操作层 38px + 页签层 32px。
- 聊天内容左右 20px，最大宽度 1000px；助手卡内边距 16px 20px。
- Composer 左右和底部均为 20px，最小高度 116px，8px 圆角，无浮空大阴影。

## 字体

- 界面字体：`PingFang SC, SF Pro Text, Helvetica Neue, sans-serif`。
- 标题字体：`PingFang SC, SF Pro Display, Helvetica Neue, sans-serif`。
- 代码字体：`SFMono-Regular, Cascadia Code, Roboto Mono, monospace`。
- 页面标题 16px / 600；会话标题与正文 14px / 510、400；辅助文本 11–12px。
- 消息正文行高约 24px（14px × 1.7），中文标题字距为 0。

## 响应式

- `≤1150px`：收起分组栏，保留应用导航、列表、6px gutter 与聊天。
- `≤900px`：继续收起应用导航，保留列表、6px gutter 与聊天。
- `≤680px`：默认显示全宽聊天，通过返回按钮切换全宽列表；页面保留 6px 外框。

## 本轮参考修正

- 第一版的连续大平面改为三个清楚的空间层级：外框导航、分组+列表联合面板、独立聊天面板。
- 暗黑聊天从大面积纯黑改为 `#181818` 画布上的 `#2c2c2c` 助手卡；用户气泡使用暗蓝选中色。
- 工具代码卡与权限卡收进助手卡，保持紧凑完整，不再散落在聊天画布上。
- Composer 改为贴底薄边容器，主题菜单、悬停、聚焦与弹层均绑定对应主题变量。
- 未在本轮调用导出；按要求仅做静态检查，浏览器截图验证由后续主流程执行。
