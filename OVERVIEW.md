Feishu UI adds Feishu-inspired light and dark themes, selected in Settings → Appearance as 飞书 · 浅色 and 飞书 · 暗黑. On desktop and in a browser, the themes also restyle navigation, chat bubbles, and tool cards, with expandable first-line previews of reasoning text exposed by the provider. Native iOS and Android receive theme colors only. Both the app and daemon must run Paseo 0.8 through 0.11; Windows desktop is untested. Desktop styling depends on Paseo's page structure and needs verification after host upgrades. Labels are in Chinese. The plugin runs only in the client: it reads the appearance preference and rendered transcript, and writes to the clipboard only when a copy button is pressed. It does not access workspace files or make network requests. It is an independent community theme and does not connect to Feishu services.
