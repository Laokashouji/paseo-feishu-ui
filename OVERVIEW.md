Feishu UI adds Feishu-inspired light and dark themes, selected in Settings → Appearance as 飞书 · 浅色 and 飞书 · 暗黑. On desktop and in a browser, the themes also restyle navigation, chat bubbles, and tool cards, with expandable first-line previews of reasoning text exposed by the provider. Native iOS and Android receive theme colors only.

Both the app and daemon require Paseo 0.8 or later. The desktop adapter supports the changed sidebar and tool-card structures in Paseo 0.16. Windows desktop is untested, and future host layouts need verification. Labels are in Chinese. The plugin runs only in the client: it reads the appearance preference and rendered transcript, and writes to the clipboard only when a copy button is pressed. It does not access workspace files or make network requests. It is an independent community theme and does not connect to Feishu services.
